Data Science / Python Analyst Intern

Familiarity with scikit-learn, Git, and software development best practices is a plus.

Requirements:
- B.Tech or equivalent degree in Computer Science, Data Science, Information Technology, or a related field
- Practical Python and SQL skills
- Understanding of data preprocessing, feature engineering, and model evaluation
- Ability to explain analysis clearly and work collaboratively
